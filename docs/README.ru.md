# BASANOS

**BASANOS** (βάσανος) — лидийский **пробирный камень** для Solidity экосистемы.
Подписанный assurance pack на закреплённом commit.

`forge.modelmarket.dev` — это **HEPHAESTUS** (кузница). Этот узел — камень, о который скребут сплав.

**Capability:** `agent.security.contract-assurance@v1`

| Узел | Вопрос |
|---|---|
| HEPHAESTUS | Собрать и оценить цепочку capabilities? |
| THEMIS | Пускать агента в каталог Hub? |
| MOMUS | Живая федерация дырявая? |
| BASANOS | Solidity на commit X звучит? |
| AgentAuditPool | Кто поставил USDC и какой `scoreBps` опубликовал? |

BASANOS не выдаёт `scoreBps` и не вызывает `coverListing`.

При FAIL / REVIEW pack несёт **только рекомендации** (ISO/IEC 29147, ISO/IEC 30111,
NIST SP 800-61): не деплоить этот digest, проверить приватно, патч, повторный скан,
раскрытие после фикса или 90 дней CVD. Паузу on-chain и эксплойт BASANOS не делает.

Четвёртый вердикт — `NO_SUBJECT`: Solidity не прочитан, значит pack ничего не оценивает.
Это не «чисто» и не обвинение. Запрос корня `acex` из автономного клона даёт именно его.
Свои фикстуры (`roots: ["fixtures"]`) работают всегда; для своего дерева — `BASANOS_CONTRACT_ROOT`.
